# 🎬 YouTube Downloader (Windows, portable)

Application Windows portable pour enregistrer des vidéos ou l'audio **dont vous avez les droits**. Portable Windows app to save videos or audio **you have the rights to**.

## ⬇ Télécharger / Download
**[YouTube-Downloader-portable.zip — dernière version / latest release](https://github.com/Walmes1/youtube-downloader/releases/latest)**

1. Dézipper / Unzip
2. Lancer / Run `YouTube-Downloader\YouTube-Downloader.exe` — aucune installation / no installation needed

> ⚠️ Windows SmartScreen peut afficher « Éditeur inconnu » (exe non signé) : *Informations complémentaires → Exécuter quand même*.

## ⚖️ Utilisation responsable / Responsible use
- 🇫🇷 Téléchargez uniquement vos propres vidéos, des contenus libres de droits (ex. Creative Commons, domaine public) ou des contenus pour lesquels vous avez l'autorisation de l'auteur. Les [Conditions d'utilisation de YouTube](https://www.youtube.com/t/terms) interdisent le téléchargement sans autorisation. Vous êtes seul responsable de l'usage que vous en faites.
- 🇩🇪 Laden Sie nur eigene Videos, gemeinfreie / frei lizenzierte Inhalte oder Inhalte mit Erlaubnis des Urhebers herunter. Die YouTube-Nutzungsbedingungen verbieten das Herunterladen ohne Erlaubnis.
- 🇬🇧 Only download your own videos, public-domain / freely licensed content, or content you have the author's permission for. YouTube's Terms of Service prohibit downloading without permission. You are solely responsible for how you use this tool.
